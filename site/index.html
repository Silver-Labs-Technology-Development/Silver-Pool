FEES AND REWARDS

Pool Fees

Silver Pool charges a 2.00% fee on miner rewards. The fee is configurable by the pool operator within a 0.00% – 5.00% range via the BTCS_POOL_FEE environment variable.

Default fee: 2.00%

Minimum fee: 0.00%

Maximum fee: 5.00%

Fee recipient: BTCS_POOL_FEE_ADDRESS

Minimum payout: 0.01 BTCS

Payout check interval: 300 seconds (5 min)

Automatic payouts: disabled until verified end-to-end

MINING

How to Mine BTCS

Silver Pool uses the Stratum V1 protocol over TCP. Miners connect with a worker name and mine directly to the pool.

Pool Connection

Stratum endpoint: stratum.silver-pool.example:3456

User format: WALLET_ADDRESS.WORKER_NAME

Replace stratum.silver-pool.example:3456 with the actual pool hostname when deployed.

Miner Configuration

# Example for CCMiner/SGminer/BMiner
SERVER=stratum.silver-pool.example:3456
USER=btcs1qxyz...worker1
PASS=x

Replace the server address with the deployed pool hostname.
