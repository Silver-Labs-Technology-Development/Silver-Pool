Response envelope

Success and error responses use the same top-level shape.

{
  "ok": true,
  "data": { },
  "meta": { "timestamp": 0, "request_id": "..." }
}

Errors use "ok": false and an error object with code, message and optional details.

Quick check

Verify that the API is alive and the database is reachable.

curl -sS …/api/health

No secrets in this API. It does not expose RPC URLs, RPC credentials, wallet private material, payout addresses or signing controls. Blocks and miners are public pool records.
